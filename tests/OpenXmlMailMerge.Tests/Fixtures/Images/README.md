# Image fixtures

Real image files, one or more per format the library recognizes, used by the image tests. They are unmodified copies
from the projects below, downloaded in October 2026. Vector sizes are the header's physical size at 96 DPI.

| `peacock.progressive.jpeg` | JPEG, progressive (SOF2) | 100 × 75 | Wuffs | CC0 1.0 (2) |
| `hippopotamus.regular.png` | PNG | 36 × 28 | Wuffs | Public domain (1) |
| `hippopotamus.interlaced.png` | PNG, interlaced | 36 × 28 | Wuffs | Public domain (1) |
| `hippopotamus.regular.gif` | GIF | 36 × 28 | Wuffs | Public domain (1) |
| `hippopotamus.interlaced.gif` | GIF, interlaced | 36 × 28 | Wuffs | Public domain (1) |
| `hippopotamus.bmp` | BMP, BITMAPV5HEADER | 36 × 28 | Wuffs | Public domain (1) |
| `pal8.bmp` | BMP, BITMAPINFOHEADER | 127 × 64 | [BMP Suite 2.8](https://entropymine.com/jason/bmpsuite/) | Public domain (3) |
